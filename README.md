# drivers_fastest_lap_compared_F1
Compares the fastest lap of two drivers in the same session and whether the drivers are braking or not, all displayed as graphs. Uses FastF1 API.

To run:
```
python driverLapComparison.py <year> <weekend> <driver1> <driver2>
```

eg: python driverLapComparion.py 2023 22 VER LEC

To move to the next lap, press the Right arrow key.
To move to the previous lap, press the Left arrow key.
